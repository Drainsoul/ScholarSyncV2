About ScholarSync

ScholarSync is a scholarship platform. Students build a profile, see which programs they may qualify for, apply with their documents and follow their allowances. Program staff review applications and manage scholars. A scholarship office oversees every program.

An independent project

ScholarSync is an independent portfolio project by Kenneth. It is not an official service of the City of Taguig, and it is not affiliated with or endorsed by the City. The "City of Taguig" label in the page header is part of the sample design. All sample people and data are fictional.

Open source

The code is open source under the MIT license, and anyone may run their own copy. The person or organisation that runs a copy is responsible for the data in it. This copy is run by {{ operator_name }}. The source code is on GitHub.

Try it

  • Run your own copy on your computer with docker compose up. The README explains how.
  • A copy started that way comes with fictional test accounts for a student, a program staff member and a scholarship office administrator.
  • Read the FAQ for the common questions.
