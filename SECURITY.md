# Security policy

ScholarSync is an independent portfolio project. It handles personal data when someone hosts it, so security reports
are welcome.

## Reporting a vulnerability
Please report it **privately**. Do not open a public issue, pull request or discussion about it.

1. Go to the repository's **Security** tab on GitHub.
2. Choose **Report a vulnerability** (GitHub's private vulnerability reporting).
3. Describe the problem, how to reproduce it and what it could allow. Do not include real personal data.

You will get an answer as soon as the maintainer can give one. This is a one-person project, so there is no fixed
response time. Please allow a reasonable period to fix the problem before you share it publicly.

## Scope
This repository's code. A hosted copy's configuration and data are the responsibility of its operator: report problems
with a particular site to that site's operator (see its contact page).
