# M2 Scaffold + Tooling Implementation Plan

**Goal:** Turn the empty repository into the real ScholarSync V2 project skeleton on `main`:
- a Django 5.2 LTS app with fail-fast settings, a `core` app (health check, home page, security headers);
- JSON logging and Sentry scrubbing, with CSP in report-only mode;
- a Vite + strict TypeScript + Biome front end rendered through a base layout;
- the Vercel build/deploy configuration proven in M1;
- mypy, and a GitHub Actions CI workflow whose every command passes locally.

**Architecture:** One Django project.
- `config/` holds settings, URLs and WSGI.
- Apps live under `apps/` (`apps.core` first).
- Templates live in `templates/`, and the Vite root in `frontend/` (built to `static/dist/`, served through django-vite and
  WhiteNoise's manifest storage).
- `build.py` is Vercel's build step: Vite → collectstatic → migrate + `createcachetable` on the unpooled URL.
- Everything that M1 proved on the spike branch is re-implemented here test-first. The spike branch is reference only
  and is never merged.

**Tech Stack:**
- Python 3.13 (uv 0.13), Django 5.2.18, environs 15.2, psycopg 3.3;
- django-vite 3.2, whitenoise 6.12, django-csp 4.0, sentry-sdk 2.72;
- pytest 9.1, pytest-django 4.14, pytest-xdist 3.8, factory-boy 3.3, ruff 0.17, mypy 2.4 + django-stubs 6.1.2,
  pip-audit 2.10;
- Vite 8.3.4, TypeScript 7.0.2, @types/node 22.20.5, @biomejs/biome 2.5.15;
- GitHub Actions: checkout v7, setup-node v7, setup-uv v10.

## Global Constraints
- **Versions:** Python `>=3.13,<3.14`; Django `>=5.2.18,<5.3`; Node `>=22.12` (Vite 8).
- **Time zone and money:** `TIME_ZONE = "Asia/Manila"`, `USE_TZ = True`. Money fields arrive in later milestones as
  `DecimalField(12, 2)`.
- **Settings:**
  - one module, `config/settings.py`, read with environs;
  - **no insecure fallbacks**: `DJANGO_SECRET_KEY` and `DATABASE_URL` are required, with no default (spec §14);
  - with `DJANGO_DEBUG` unset, debug is off.
- **Database:** `CONN_MAX_AGE=0`, `CONN_HEALTH_CHECKS=True`, `DISABLE_SERVER_SIDE_CURSORS=True`; cache is
  `DatabaseCache` (`django_cache`).
- **Security headers when not DEBUG:**
  - HSTS 31536000 + includeSubDomains, `SECURE_SSL_REDIRECT`, secure session/CSRF cookies;
  - always: `nosniff`, `Referrer-Policy: same-origin`, `Cross-Origin-Opener-Policy: same-origin`,
    `X-Frame-Options: DENY`, `Permissions-Policy`.
- **CSP:**
  - report-only unless `CSP_REPORT_ONLY=false`;
  - `default-src 'self'`; `script-src 'self'`; `style-src 'self'`; `img-src 'self' data:`; `connect-src 'self'`;
    `frame-ancestors 'none'`; `form-action 'self'`; `base-uri 'self'`; `object-src 'none'`;
  - templates contain **no inline `<script>` or `style=`**.
- **Logs:** JSON lines to stdout with no PII.
- **Sentry:** only when `SENTRY_DSN` is set, with `send_default_pii=False`; `before_send` strips request
  data/cookies/headers and the user email.
- **Vercel:**
  - region `sin1`;
  - `includeFiles` bundles `static/dist/.vite/manifest.json` **and** `staticfiles/staticfiles.json`;
  - `/static/(.*)` gets `Cache-Control: public, max-age=31536000, immutable`;
  - `.vercelignore` keeps `.env*`, local notes, local build output and `docs/` out of deploys.
- **Front-end budget:** JS + CSS ≤ 100 KB gzipped (spec §12).
- **Local Postgres:** compose, host port **5433** (5432 is often taken by a native PostgreSQL).
- **Windows shells:**
  - run uv as `python -m uv` (it isn't on PATH);
  - PowerShell 5.1 has no `&&`;
  - the first npm install runs **inside** `frontend/` (`npm --prefix frontend install` breaks on npm 10);
    `npm --prefix frontend ci|run` work.
- **Git:**
  - commit every task to `main`;
  - Conventional Commits;
  - nothing pushed.
  - CI can only run on GitHub once the work is pushed. Until then, every CI command is run locally.
- **Ruff:** `extend-exclude = ["docs"]` (ruff 0.17 formats Python code blocks inside Markdown).

## Review Focus
1. **Missing required env vars:** with `DJANGO_SECRET_KEY` or `DATABASE_URL` unset, the app must refuse to start,
   with an error naming the variable, and never fall back to a default. *Test:* Task 1
   `test_settings_refuse_to_load_without_required_vars`.
2. **Sentry leaking PII:** an event carrying request cookies, an `Authorization` header, form data or `user.email` must
   reach Sentry without them. *Test:* Task 3 `test_scrub_event_removes_request_and_user_pii`.
3. **Headers on every response:** security headers and the CSP header must appear on error responses (404) too, not
   just on 200 pages. *Test:* Task 2 `test_security_headers_on_404`.
4. **Inline script or style sneaking into templates:** this would break once CSP is enforced. *Test:* Task 4
   `test_templates_have_no_inline_script_or_style`.
5. **A clean checkout without a built front end:** tests must still pass (the fixture builds Vite and resets
   django-vite's cached loader). A deploy must never ship without both manifests. *Tests:* Task 4 (fixture + home page
   test) and Task 5 `test_vercel_function_bundles_both_runtime_manifests`.

`apps/core/middleware.py`:
```python
from collections.abc import Callable

from django.conf import settings
from django.http import HttpRequest, HttpResponse


class PermissionsPolicyMiddleware:
    """Adds the Permissions-Policy header (Django has no setting for it)."""

    def __init__(self, get_response: Callable[[HttpRequest], HttpResponse]) -> None:
        self.get_response = get_response

    def __call__(self, request: HttpRequest) -> HttpResponse:
        response = self.get_response(request)
        response.setdefault("Permissions-Policy", settings.PERMISSIONS_POLICY)
        return response
```

```python
import json
import logging
from datetime import UTC, datetime


class JsonFormatter(logging.Formatter):
    """One JSON object per line for Vercel's log viewer. Never log names, emails or documents."""

    def format(self, record: logging.LogRecord) -> str:
        payload = {
            "ts": datetime.fromtimestamp(record.created, UTC).isoformat(),
            "level": record.levelname,
            "logger": record.name,
            "msg": record.getMessage(),
        }
        if record.exc_info:
            payload["exc"] = self.formatException(record.exc_info)
        return json.dumps(payload, ensure_ascii=False)
```

```python
from typing import Any

SAFE_HEADERS = {"User-Agent", "Referer", "Content-Type", "Accept", "Host"}


def scrub_event(event: dict[str, Any], hint: dict[str, Any]) -> dict[str, Any]:
    """Drop request bodies, cookies, query strings, auth headers and user identity except the id."""
    request = event.get("request")
    if isinstance(request, dict):
        for key in ("data", "cookies", "query_string", "env"):
            request.pop(key, None)
        headers = request.get("headers")
        if isinstance(headers, dict):
            request["headers"] = {k: v for k, v in headers.items() if k in SAFE_HEADERS}
    user = event.get("user")
    if isinstance(user, dict):
        event["user"] = {"id": user["id"]} if "id" in user else {}
    return event


def init_sentry(*, dsn: str, environment: str, release: str | None) -> None:
    import sentry_sdk
    from sentry_sdk.integrations.django import DjangoIntegration

        dsn=dsn,
        environment=environment,
        release=release,
        integrations=[DjangoIntegration()],
        send_default_pii=False,
        before_send=scrub_event,  # type: ignore[arg-type]
        traces_sample_rate=0.0,
    )
```

```js
// Fails the build when the gzipped JS + CSS referenced by the Vite manifest exceed the budget (spec §12).
import { readFileSync } from "node:fs";
import { dirname, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { gzipSync } from "node:zlib";

const LIMIT_BYTES = 100 * 1024;
const dist = resolve(dirname(fileURLToPath(import.meta.url)), "../../static/dist");
const manifest = JSON.parse(readFileSync(resolve(dist, ".vite/manifest.json"), "utf8"));

const files = new Set();
for (const entry of Object.values(manifest)) {
  if (entry.file) files.add(entry.file);
  for (const css of entry.css ?? []) files.add(css);
}

let total = 0;
for (const file of files) {
  if (!/\.(js|css)$/.test(file)) continue;
  total += gzipSync(readFileSync(resolve(dist, file))).length;
}

const kb = (total / 1024).toFixed(1);
if (total > LIMIT_BYTES) {
  console.error(`budget: ${kb} KB gzipped exceeds ${LIMIT_BYTES / 1024} KB`);
  process.exit(1);
}
console.log(`budget: ${kb} KB gzipped (limit ${LIMIT_BYTES / 1024} KB)`);
```

`build.py`:
```python
"""Vercel build step: front end, static files, then migrations on the unpooled database URL.

Vercel runs this after installing Python dependencies (pyproject `[tool.vercel.scripts] build`).
collectstatic runs here, after the Vite build, so `staticfiles.json` never depends on when
Vercel's own collectstatic runs (it runs after this script; see the M1 spike results).
"""

import os
import shutil
import subprocess
import sys
from collections.abc import Mapping
from pathlib import Path

ROOT = Path(__file__).resolve().parent


def steps(npm: str, python: str) -> list[list[str]]:
    return [
        [npm, "--prefix", "frontend", "ci"],
        [npm, "--prefix", "frontend", "run", "build"],
        [python, "manage.py", "collectstatic", "--noinput"],
        [python, "manage.py", "migrate", "--noinput"],
        [python, "manage.py", "createcachetable"],
    ]


def migration_env(environ: Mapping[str, str]) -> dict[str, str]:
    env = dict(environ)
    unpooled = env.get("DATABASE_URL_UNPOOLED", "")
    if unpooled:
        env["DATABASE_URL"] = unpooled
    return env


def main() -> int:
    npm = shutil.which("npm") or "npm"
    env = migration_env(os.environ)
    for command in steps(npm, sys.executable):
        print("build: running", " ".join(command[1:]), flush=True)
        subprocess.run(command, check=True, cwd=ROOT, env=env)  # noqa: S603
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
